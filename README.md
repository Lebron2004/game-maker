# Game Maker

Small browser games and tools, each one a single HTML file with no build step.

| Project | What it is |
| --- | --- |
| [Sprout Acres](sprout-acres/) | A cozy farming sim: plant, water and harvest crops. |
| [Prompt Arcade](prompt-arcade/) | Describe a game in words and get a playable one. Making new games needs Claude; outside Claude it plays the built-in example. |
| [Splice](splice-video-editor/) | A simple in-browser video editor with a track timeline. |

## Playing

Open any `index.html` in a browser, or turn on GitHub Pages (Settings, Pages, deploy from the `main` branch) and visit `https://lebron2004.github.io/game-maker/<folder>/`.
