My games

Games you make show up here, so you can play them again later.

Games are made with your Claude account, so there is no API key to set up. The first time you click Make it, Claude asks you to allow this page. Each game takes about a minute on Fast and a few minutes on Best. Click the game screen before using the keyboard.
